## 주제별 보기

한 논문이 여러 주제에 속할 수 있습니다. 서베이와 방법론은 유형으로, 미독과 완독은 읽기 상태로 따로 관리합니다.

- [비디오 월드 모델](topics/video-world-models.md): 15편. 영상으로 세계 상태와 시간에 따른 변화를 모델링하는 연구.
- [비디오 이해](topics/video-understanding.md): 1편. 영상의 의미, 공간, 시간, 물리 및 인과 관계를 이해하는 연구.
- [비디오 생성](topics/video-generation.md): 9편. 영상을 생성하거나 편집하고 미래 장면을 예측하는 연구.
- [행동 학습과 에이전트](topics/embodied-agents.md): 5편. 관측과 영상 계획을 실제 행동, 제어, 환경 상호작용으로 연결하는 연구.
- [위치·상태 전이 (pos transition)](topics/pos-transition.md): 3편. 위치·상태 전이 모델링을 위해 참고한 논문.
- [RL + Diffusion](topics/rl-diffusion.md): 4편. 강화학습으로 diffusion·flow matching 생성 모델을 최적화하는 연구.
- [Diffusion 증류](topics/diffusion-distillation.md): 2편. Diffusion 생성 모델을 한 번 또는 소수의 생성 단계로 가속하는 증류·분포 매칭 연구.
- [표현 학습](topics/representation-learning.md): 1편. 모델이 학습한 표현의 구조와 정렬·수렴을 다루는 연구.
- [Code World Model](topics/code-world-model.md): 10편. 코드로 실행되는 세계·규칙과 생성 렌더러를 다루는 논문 읽기 목록.

## 내용으로 다시 찾기

이 프로젝트의 채팅에서는 ‘보관한 논문 중 마인크래프트에서 영상으로 행동을 배우는 거 찾아줘’처럼 말하면 됩니다. 다른 채팅에서는 이 공개 저장소 링크를 함께 주고 검색을 요청하세요. 내용을 읽을 수 있는 웹 도구, GitHub 연결 또는 로컬 파일 접근이 필요합니다.

로컬에서 키워드로 찾으려면:

```bash
python3 scripts/archive.py search "마인크래프트 행동"
python3 scripts/archive.py search "월드모델 서베이"
```

## 기록과 수정

`catalog.json`에 제목, 저자, 원문 링크, 한글 요약, 분류, 검색 키워드, 읽기 상태, 사용자 메모를 저장합니다. 새 논문을 등록할 때 arXiv ID가 같은 항목은 중복 생성하지 않고 갱신합니다. 원문은 arXiv 및 PDF 링크로 보관합니다.

분류표와 논문별 메모는 아래 명령으로 갱신합니다:

```bash
python3 scripts/archive.py build
python3 scripts/archive.py check
```

[엑셀 내려받기](paper_archive.xlsx)는 2026-10-24에 만든 초기 스냅샷입니다. 최신 목록은 이 페이지와 `catalog.json`에서 확인합니다.
